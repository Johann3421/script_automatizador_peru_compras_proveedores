FLUJO DETALLADO — modulo_subir_pdf (corrección de fichas + PDF)
================================================================

OBJETIVO
--------
Tomar un Excel con productos a corregir (características + N° de parte + certificaciones)
y aplicar las correcciones en PeruCompras masivamente.

ARCHIVO DE ENTRADA
------------------
Excel: LISTA_CORRECCION_VALORES_FICHA OBSER._PC_KENYA_REASIGN..xlsx
Hoja: REASIGNACION (1053 filas, 30 columnas)

COLUMNAS DEL EXCEL (auto-detectadas por nombre)
------------------------------------------------
- N°                  : índice (1, 2, 3, ...) — NO se usa
- FICHA N°            : ID INTERNO de PeruCompras (2267958, etc.) — CLAVE DE BÚSQUEDA
- IMAGEN (PDF)        : modelo (texto libre, no se usa para el flujo)
- FICHA TECNICA (PDF) : N° de parte NUEVO que debe quedar (EMU5R6000, etc.)
- PRECIO SUGERIDO     : no se usa
- PROCESADOR a SISTEMA DE MANEJO DE RAEE : columnas de características a comparar/corregir
- CERTIFICACION 1..5  : certificaciones esperadas (5 cols)

Cada fila del Excel se mapea a un dict con:
  {
    "parte": <N° de parte NUEVO del Excel>,    # ej "EMU5R6000"
    "ficha": <FICHA N° del Excel>,             # ej "2267958"  ← BÚSQUEDA
    "caracteristicas": {nombre: valor_esperado},
    "certs_esperadas": [listado de 5 certs],
  }

FLUJO PRINCIPAL (por cada producto)
------------------------------------
1. BÚSQUEDA POR FICHA (no por N° de parte)
   - El N° de parte del Excel es NUEVO (todavía no existe en PeruCompras).
   - Se busca por FICHA N° (columna "FICHA N°") usando el endpoint API:
     GET /t_CatalogoProductoMarca/_CatalogoProductoIndex
       ?N_Catalogo=252
       &N_Categoria=11735
       &C_Descripcion={FICHA N°}    ← se usa la ficha como query
       &C_EstadoNav=OBSERVADO
   - Devuelve el ID_CatalogoProducto (ID interno de PeruCompras, ej 2380651).

2. NAVEGACIÓN DIRECTA A LA FICHA DE EDICIÓN
   - URL: /t_CatalogoProductoMarca/CatalogoProductoEdit
            ?ID_CatalogoProducto={id}
            &C_EstadoNav=OBSERVADO
            &C_Moneda=USD
   - Más rápido que pasar por la lista de búsqueda (la tabla con miles de fichas
     tarda 5+ minutos en cargar).

3. SUBIR PDF
   - Selector: input[type="file"] con id #AdjFile
   - Llamada: file_input.set_input_files(ruta_pdf)
   - Espera 3s para que PeruCompras procese.
   - El PDF es el que está en PDF_DIR con el nombre del N° de parte nuevo.

4. GUARDAR
   - Selector: #btnGuardar
   - Espera el modal de éxito (cualquiera de: #MensajeModal, #modalContent, .bootbox.modal).
   - Timeout: 360s (PeruCompras es lento).
   - Si no aparece modal: asumir guardado OK y continuar.
   - Cierra el modal con #btnSalir o "Aceptar".

5. LEER CARACTERÍSTICAS DE LA PÁGINA
   - Tabla con rows que tienen .col-md-4 (hidden inputs + nombre + valor).
   - Cada char tiene: nombre, valor, id (ID_CatFichaProducto).
   - El ID se usa para abrir el modal de edición.

6. COMPARAR CON EXCEL
   - Por cada char del Excel, busca match en la página por nombre.
   - Si los valores no coinciden, agrega a la lista de "diferentes".

7. CORREGIR CADA DIFERENCIA
   - Llama a link_caracteristicaEdit(id, 'OBSERVADO') por JS.
   - Espera el form #form_editCaracteristica.
   - Lee opciones del dropdown #N_ValCaracteristica.
   - Busca match en 3 niveles:
     1. EXACTO: "SI" == "SI"
     2. SUFIJO: "SI" matchea "TECLADO: SI" o "MOUSE: SI"
     3. CONTAINS: cualquier opción que contenga el valor
   - Selecciona y click en #btn_guardar.
   - Cierra modal de éxito.
   - Si la página se recargó (link_caracteristicaEdit no está disponible),
     re-navega a edit_url antes de continuar.

8. AGREGAR CERTIFICACIONES FALTANTES
   - Lee tabla de certificaciones de la página.
   - Compara con certs_esperadas del Excel.
   - Certs no-ISO (CE, RoHS, FCC) que falten: SKIP (no se pueden agregar automáticamente).
   - ISO 9001 y 14001 faltantes: agregar usando agregar_caracteristicas() (función
     original de modulo_modificar_productos que abre #wm_caracteristicaNueva).

PROBLEMAS CONOCIDOS
-------------------
1. PeruCompras es LENTO:
   - Búsqueda con tabla: 5+ minutos con miles de fichas
     → Solución: usar API search + navegación directa a edit URL
   - Modal de éxito tras guardar: puede tardar minutos
     → Solución: timeout 360s
   - El campo select2 de la ficha puede tardar en cargar opciones
     → Solución: polling hasta 10 intentos con 1.5s c/u

2. Detección de sesión:
   - Cuando ya hay sesión, /AccesoGeneral redirige a la raíz
     → Solución: _tiene_campos_login() — verificar que existan los inputs
       antes de intentar login
   - URL con accesogeneral o login + sin inputs = sesión activa

3. Modal de éxito tiene múltiples selectores:
   - #MensajeModal (después de Guardar principal)
   - #modalContent (después de editar característica)
   - .bootbox.modal (genérico)
   - Cerrar con #btnSalir o texto "Aceptar"/"Cerrar"/"OK"

4. link_caracteristicaEdit se pierde tras guardar:
   - El form submit recarga la página
   - Solución: re-navegar a edit_url entre correcciones

5. SI/NO match:
   - Excel tiene "SI" o "NO" (sin prefijo)
   - Página tiene "TECLADO: SI", "MOUSE: NO", etc.
   - Solución: match por sufijo ": SI" o ": NO"
