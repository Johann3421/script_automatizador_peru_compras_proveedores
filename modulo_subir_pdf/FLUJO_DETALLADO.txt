2. NAVEGACIÓN — PÁGINA DE GESTIÓN
================================================================================
URL: https://www.catalogos.perucompras.gob.pe/t_CatalogoProductoMarca

Esta página carga un formulario con 4 dropdowns tipo Select2:
  - ajaxAcuerdo    (Acuerdo Marco)
  - ajaxCatalogo   (Catálogo Electrónico)
  - ajaxCategoria  (Categoría)
  - ajaxEstado     (Estado)

Cada dropdown es un <select> oculto con un widget Select2 superpuesto.
El contenedor visible de cada Select2 tiene ID: select2-{select_id}-container

Dropdown values para EXT-CE-2022-5 (Computadoras/Escáneres):
  ajaxAcuerdo     = 249  (EXT-CE-2022-5 COMPUTADORAS DE ESCRITORIO, COMPUTADORAS PORTÁTILES Y ESCÁNERES)
  ajaxCatalogo    = 251  (ESCÁNERES)
                    = 252  (COMPUTADORAS DE ESCRITORIO)
                    = 253  (COMPUTADORAS PORTÁTILES)
  ajaxCategoria   = (depende del catálogo, ej: 11734, 11735, 11737, etc.)
  ajaxEstado      = ACTIVO | PENDIENTE | OBSERVADO | SUBSANADO | APROBADO

La cascada funciona así:
  ajaxAcuerdo → cambia → ajaxCatalogo recarga opciones
  ajaxCatalogo → cambia → ajaxCategoria recarga opciones
  ajaxCategoria → cambia → ajaxEstado recarga opciones (o no si ya tiene)

Cómo seleccionar en Select2:
  1. Hacer click en el contenedor: #select2-{id}-container
  2. Esperar que aparezca la lista: li.select2-results__option
  3. Click en la opción por texto
  4. O usar JS directo: document.getElementById(id).value = valor;
     + dispatchEvent('change') + $(sel).trigger('change.select2')

Botón Buscar: #btnBuscar
  Al hacer click, la página hace un postback ASP.NET y carga la tabla de resultados.

3. TABLA DE RESULTADOS
================================================================================
Tabla ID: #TablaProductos (con T mayúscula)
Estructura: table > tbody > tr (cada fila = una ficha de producto)

La tabla usa DataTables con campo de búsqueda:
  Input: #C_Descripcion (placeholder="Descripción a Buscar")

Flujo de búsqueda por N° de Parte:
  1. Escribir el part number en #C_Descripcion
  2. Click en #btnBuscar nuevamente
  3. Esperar a que la tabla se filtre (puede tardar hasta 3 minutos con estado OBSERVADO)
  4. Verificar que la fila filtrada aparezca

Cada fila contiene un link "Editar":
  <a href="#" onclick="location.href='/t_CatalogoProductoMarca/CatalogoProductoEdit?ID_CatalogoProducto={ID}&C_EstadoNav=OBSERVADO&C_Moneda=USD'">Editar</a>

Selector: a[onclick*='CatalogoProductoEdit']

4.3 AÑADIR CERTIFICACIONES (ISO 9001 + ISO 14001)
------------------
Botón: #btn_caracteristicaNueva
  <button id="btn_caracteristicaNueva" title="Nueva Característica">
      Añadir Características
  </button>

Al hacer click, se abre un BOOTBOX modal con un formulario:
  <div id="modalBody" class="modal-body">
    <div class="form-horizontal">
      <input type="hidden" id="C_EstadoNav" name="C_EstadoNav" value="OBSERVADO">
      <select id="N_Caracteristica" name="N_Caracteristica">
        <option value="0">Seleccione Característica</option>
        <option value="26229">CERTIFICACION</option>
      </select>
      <select id="N_ValCaracteristica" name="N_ValCaracteristica">
        <option value="1597409">ISO 9001</option>
        <option value="1661118">ISO 9001</option>
        <option value="1661123">ISO 14001</option>
        ... (más opciones)
      </select>
      <input type="hidden" id="N_CatalogoProducto" value="{ID}">
    </div>
  </div>

El footer del modal tiene botones:
  - Guardar → button:has-text('Guardar') en .modal-footer
  - Cancelar → data-dismiss="modal"

Proceso para cada ISO:
  1. Seleccionar "CERTIFICACION" (value=26229) en #N_Caracteristica
  2. Esperar que cargue #N_ValCaracteristica
  3. Buscar el ISO en las opciones (por texto "ISO 9001" o value 1597409/1661118)
  4. Si NO está en las opciones → ya fue agregado anteriormente → SALTAR
  5. Seleccionar el value del ISO en #N_ValCaracteristica
  6. Click en Guardar del modal
  7. Aparece MODAL de confirmación: "Se registro satisfactoriamente!"
  8. Cerrar modal con #btnSalir
  9. Repetir desde paso 1 para el siguiente ISO

ISOs a agregar: ISO 9001, ISO 14001

5. POSIBLES ENDPOINTS HTTP PARA BULK PROCESSING
================================================================================

Para hacer esto en masa sin navegador, se necesita descubrir los endpoints POST.
Con Playwright se puede interceptar las requests usando page.route() o
page.on('request') para capturar:

5.1 Guardar PDF (endpoint probable)
------------------
POST /t_CatalogoProductoMarca/CatalogoProductoEdit
Content-Type: multipart/form-data
Campos:
  - __RequestVerificationToken
  - AdjFile (archivo PDF)
  - btnGuardar = Guardar
  - ID_CatalogoProducto
  - C_EstadoNav
  - otros campos del formulario

5.2 Guardar Característica (endpoint probable)
------------------
POST /t_CatalogoProductoMarca/CatalogoProductoEdit (mismo URL, diferente acción)
Content-Type: application/x-www-form-urlencoded
Campos:
  - __RequestVerificationToken
  - N_Caracteristica = 26229 (CERTIFICACION)
  - N_ValCaracteristica = {value del ISO}
  - N_CatalogoProducto = {ID del producto}
  - C_EstadoNav
  - btn_caracteristicaNueva o similar

5.3 Búsqueda de productos (endpoint probable)
------------------
POST /t_CatalogoProductoMarca
Content-Type: application/x-www-form-urlencoded
Campos:
  - ajaxAcuerdo
  - ajaxCatalogo
  - ajaxCategoria
  - ajaxEstado
  - C_Descripcion (part number)
  - btnBuscar

La respuesta es HTML que contiene la tabla #TablaProductos.
Se puede parsear con BeautifulSoup para extraer:
  - ID_CatalogoProducto del onclick del botón Editar
  - Estado actual del producto

================================================================================
6. COOKIES Y TOKENS NECESARIOS
================================================================================
  - ASP.NET_SessionId  → sesión del servidor
  - .ASPXAUTH          → autenticación
  - __RequestVerificationToken → anti-CSRF (se extrae del HTML de cada página)
  - TS{xxxx} (opcional) → puede ser necesario para ciertas requests

El RequestVerificationToken cambia en cada página/formulario.
Se debe extraer del HTML: <input name="__RequestVerificationToken" type="hidden" value="...">
